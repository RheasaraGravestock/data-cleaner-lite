# Data Cleaner Lite

A beginner Python project that cleans and validates user input.

## Features

- Cleans full names
- Validates email addresses
- Removes symbols from phone numbers

## Skills Used

- Python functions
- String methods
- Lists
- Loops
- Conditionals
- Input validation

## Example

Input:

Name:       jAnE   dOE
Email:   TEST@GMAIL.COM
Phone:   (555) 123-4567

Output:

Name:  Jane Doe
Email: test@gmail.com
Phone: 5551234567
